# ExamPro — Requirements Baseline

## Project
ExamPro is a conceptual Online Exam & Test Series QA Automation Portfolio Project.

## Users
- Guest User
- Free User
- Paid User
- Admin

## Authentication
- Email/password login
- Google login entry point
- Forgot password
- Logout
- Session handling

## Test Series
- Full Length Test: 100 questions, 120 minutes
- Subject Test: 50 questions, 60 minutes
- Free and premium tests

## Exam Engine
- Question display
- Options
- Next / Previous
- Question palette
- Mark for Review
- Clear Answer
- Timer
- Submit
- Auto-submit

## Scoring
- Correct: +4
- Incorrect: -1
- Unattempted: 0

## Subscription
- Free, Basic, Premium
- Purchase, activation, renewal, cancellation
- Upgrade / downgrade
- Expiry
- Failed payment scenarios

## Admin
- Manage users
- Create/edit/delete tests
- Add/edit questions
- Manage test series
- Manage subscriptions
- View reports

## Planned Technical Coverage
- Python + Playwright + Pytest
- Allure reporting
- GitHub Actions CI/CD
- REST API validation
- SQLite database validation
- Cross-browser: Chromium, Firefox, WebKit
- Responsive, accessibility, network and authorization testing
